# qwen-dap-mcp v0.12.0

v0.12 makes the MCP surface more agent-friendly and adds a reproducible public crash-debugging lab without removing the existing low-level debugger API.

## Compact agent toolset

The default MCP surface is now the compact `agent` toolset. It exposes the high-value workflow and inspection tools a coding agent normally needs while keeping the model context smaller.

```text
QWEN_DAP_MCP_TOOLSET=agent   # default
QWEN_DAP_MCP_TOOLSET=full    # complete low-level debugger surface
```

`full` preserves the previous low-level DAP tool surface. Agent mode only filters exported MCP schemas; the underlying debugger implementation is not forked or duplicated.

See [toolsets.md](toolsets.md).

## Reproducible Crash Lab

Three small native fixtures are included:

- `null-pointer`
- `divide-by-zero`
- `bad-call-target`

Build one fixture with debug symbols and optimizations disabled:

```bash
npm run demo:build -- null-pointer
```

Reproduce it outside the debugger:

```bash
npm run demo:repro -- null-pointer
```

The build helper supports MSVC, clang++, and g++ where available. Generated binaries are ignored by Git.

See [../examples/crash-lab/README.md](../examples/crash-lab/README.md) and [demo-storyboard.md](demo-storyboard.md).

## Benchmark scaffold

`benchmark/cases.json` defines reproducible cases and `benchmark/README.md` defines three comparison modes:

- `source-only`
- `dap-raw`
- `qwen-dap-mcp`

Results deliberately separate `solved` from `verified`. The repository does not publish made-up success rates; measured run data must be supplied before the reporter can claim an improvement.

```bash
npm run benchmark:report -- benchmark/results.json
```

## Included postmortem fixes

v0.12 is based on the fully verified v0.11.4 line and therefore includes:

- explicit frozen/postmortem snapshot context,
- conservative live first-chance exception handling,
- Windows SEH crash-family normalization for minidumps while preserving raw DAP evidence,
- production-path real Windows minidump smoke coverage through `GuardedDapSession + openDump()`.
